# 土地庙传送（饥荒联机版 Mod）

用材料在**每种地形**上各建一座土地庙（每种地形全档一座），上香激活后可在地图上点选传送；
在已激活的庙旁还能制作**随身地图**，带着它随时随地缩地回庙。

> 当前进度：阶段 0-3 已完成（按地形建造 / 上香激活 / 地图点选传送 / 随身地图）。
> 跨分片传送尚未实现。版本 v0.5.0（未发布）。

## 快速上手

1. 把 `landshrine/` 整个文件夹复制到
   `<你的 Steam 库>\steamapps\common\Don't Starve Together\mods\`
2. **重启游戏**（饥荒只在启动时扫描 `mods/`）→ 主菜单「模组」→「服务器模组」→ 找到「土地庙传送」→ 启用 → 应用
3. 本 mod 是服务器模组且需要客户端配合，**联机时所有玩家都要装**；建议用新档测试

安装、测试清单、控制台调试命令、美术管线详见 [landshrine/README.md](landshrine/README.md)。
