# 《黑神话：悟空》土地庙 · 锚点机制资料

> 整理日期：2026-11-01
> 收录范围：**仅土地庙的「激活」与「传送」链路**（锚点功能）。调息之外的修行、铸造、泡制、货殖、炼丹、拾遗、挑战、谢礼等功能不在本文范围内。
> 正文每句结论后方的 `[A1]` `[B2]` 等标记对应文末[来源清单](#9-来源清单分级)的分级条目。

---

## 1. TL;DR

土地庙的锚点系统是一条闭环：

**显式交互激活（上香）→ 激活即同时成为「复活锚点」与「传送节点」→ 传送的代价被绑死在「恢复」上（每次传送必然刷新普通敌人）→ 道具可以绕开「人得站到庙前」，但绕不开刷新代价。**

它和魂系篝火的差别不在功能，而在**代价的耦合方式**：篝火是「休息」与「传送」分离、休息才有代价；本作是**传送自带休息**，你无法在不重置世界小怪的情况下移动。

---

## 2. 激活（上香）

| 项目 | 机制 |
|---|---|
| 初始状态 | 土地庙处于**锁定状态**，功能全部不可用 `[A2]` |
| 激活动作 | 玩家必须主动走上前完成一次**上香**，才激活该庙 `[A2][B2]` |
| 触发方式 | **不存在**「靠近自动点亮」，也没有拾取型解锁道具 —— 必须显式交互一次 `[A2][B1]` |
| 动作表现 | 天命人**拔一把猴毛幻化成香**插上 `[B1]` |
| 位置引导 | 未互动过的土地庙，玩家靠近时会出现**金光引路**，跟随金光即可找到庙 `[C5]` |
| 引导存在的原因 | 游戏本体**没有地图**（地图系统 2024-12 才补上），寻路完全依赖金光、金线与 NPC 提示 `[C3]` |
| 激活的持久性 | 一座庙一周目内**只需上一次香**，此后长期可用；同区域新发现的每座庙各自需要单独上香 `[A2][B2]` |

游戏内文本对这套机制的解释（土地庙「复生」妙诀原文）：

> 在土地庙拔毛上香，可**寄托元神**。即使遭难逢磨，暗丧其身，也可在最近处还魂复生。 `[A1]`

也就是说，「上香」在机制上等价于**把存档/复活锚点写入这座庙**，文本层用「元神寄托」来包装这个状态写入。

---

## 3. 复活锚点

- 天命人死亡后，从**最后一个互动过的土地庙**还魂复生 —— 不是章节起点，也不是本关初始检查点以外的位置 `[B1]`。各流程攻略统一表述为「在**最后拜过的**土地庙复活」 `[C6]`。
- 锚点绑定的是「最后互动」而非「最后激活」，因此**路过一座新庙上一炷香，复活点就跟着前移**。推图过程中这形成了天然的正反馈：推进 = 复活点自动变近 `[B1]`。
- **不存在复活次数上限**，也不存在「香烧完就不能复活」的限制（见[已证伪](#10-待核实--已证伪)）。
- 反过来说，只要忘记给眼前的庙上香就 death，复活点仍停在上一座庙，白跑一段路 —— 这是本作「上香是显式动作」带来的唯一惩罚。

## 4. 传送（缩地）

土地庙菜单中的传送项名为**缩地**，取「神仙术法，能缩地脉。一瞬之间，千里之外」之意 `[A1]`。

### 4.1 能力范围

- 可在**所有已激活的土地庙**之间任意选择目标 `[A1][B2]`。
- **跨章节可用**：能直接传回之前关卡的庙，包括已经推进到后续章节后回去 `[B2]`。
- 免费：不消耗灵蕴，不消耗次数，没有冷却 `[A1][B2]`。
- 目标必须已上香激活；未激活的庙不在列表内，且没有「已知但未解锁」的灰色条目 —— 列表就是玩家本周目的锚点集合 `[C1]`。

### 4.2 代价：传送自带一次调息

这是整套锚点系统唯一的真实成本，且**不可关闭**：

- 「使用缩地的同时视为**自动进行了一次调息**」 `[A1][B2]`。
- 调息的效果：立刻恢复全部生命值、法力、气力，消除全部异常状态，法术/变身/法宝/化身技直接转为可用，并补满葫芦中的酒 `[A1][B2]`。
- 调息的副作用：**场景中 Boss 与精英以外的敌人全部复活** `[B2]`。
- 作用域是**全场景**，不是目标庙周边的一小块范围。游戏文本的说法是「在土地庙调息，吸收天地精气，乾坤灵蕴异动，便会引出山中群怪」—— 用「乾坤灵蕴异动」来解释为什么恢复动作会惊动整片山林 `[A1]`。
- 敌人分为**小妖 / 头目 / 妖王**三档，**只有小妖会被刷新**；头目与妖王击败后永久消失，不会因调息或缩地重生 `[B2][C5]`。

由此得到两个使用姿势：

1. **负面**：刚清空的一条安全路线，任何一次传送都会重新填满小怪，跑图清怪是重复成本。
2. **正面**：想刷材料与灵蕴时，「传一下」本身就是免费的重置按钮，配合高刷新密度点位可以稳定循环（社区常见的刷灵蕴路线第一步都是「激活某庙 → 清一片 → 回庙上香/传送重置」） `[C7]`。

## 5. 脱离庙体的两个传送入口

土地庙本体是「必须物理抵达」的锚点，游戏用两个道具把这部分摩擦力拆掉，但**都不解除刷新代价**。

| | 缩地青符 | 行旅图 |
|---|---|---|
| 本质 | 回锚点快捷键 | 地图系统 + 完整传送菜单 |
| 获得 | 在**第一个土地庙**（黑风山·苍狼林-前山）上香后，由黑风山土地赠送 `[C6]` | 初入黑风山见到黑风山土地后免费解锁第一张（黑风山）；此后每到一个新地界，可在土地庙「货殖」购买该地界的行旅图 `[C3][C4]` |
| 上线时间 | 首发即有 | **2024-12-10 更新**实装 `[C3]` |
| 效果 | 打开物品栏直接使用，**返回最后拜过的土地庙** `[C6]` | 打开地图后可**直接在地图上点击土地庙进行缩地**，无需先跑回任一庙里 `[A1][C4]` |
| 能否选目标 | ❌ 只能回到当前锚点（等价于死亡复活的位置） | ✅ 列出全部已激活庙，含跨章节 |
| 使用次数 | **无限次**，无消耗 `[C2]` | 无限次（地图为地界级解锁，一次购买长期可用） `[C3]` |
| 附带调息 | 属于「回锚点」，不是缩地指令 | 通过地图缩地**同样触发一次调息**（与庙内缩地等价） `[A1]` |
| 缺图时的表现 | — | 未持有对应地界的行旅图时，界面会提示「前往土地庙进行缩地」（1.0.20 更新加入该提示） `[B3]` |
| 额外用途 | 打不动的 Boss 前撤退、精魄漏吸后回庙「拾遗」 | 可在地图上打记号（强敌 / 资源 / 宝箱 / 已到过），支持章节与章节内区域切换、多层地图上下切换 `[C4]` |

结论：最终形态是**「青符 = 免费无限的回锚点，行旅图 = 花点灵蕴买的完整传送」**，两者都保留了「传送即重置小怪」的核心代价，只是消除了跑图的时间成本。

## 6. 二周目的锚点差异

- 进入二周目（「再入轮回」）后，**所有土地庙需要重新上香**，无法直接传送 `[C1]`。
- 继承的是角色与资产状态：等级、灵光点、灵蕴、已解锁法术、天赋、装备、精魄与法宝及其强化状态 `[C1]`。
- **不继承的正是「地图已点亮」这部分状态** —— 锚点集合被整体清空，开图成本要重新付一遍。
- 一周目里靠缩地在章节间往返刷材料、回头补支线的便利性，在二周目前期同样需要先跑图补香才能恢复。

## 7. 给 mod 设计的规则提炼

把上面的描述还原成可实现的条件-效果表：

| 触发 | 效果 | 副作用 |
|---|---|---|
| 玩家对锁定态庙执行显式交互（上香） | 庙 → 已激活；写入 `lastAnchor = 本庙` | 无（一次性） |
| 玩家在任意已激活庙执行调息 | 全量资源恢复 + 葫芦/消耗品补给 | 全场景非精英敌人重置 |
| 玩家选择传送目标 T | 玩家位移至 T；`lastAnchor = T` | **强制附带一次调息** → 同上 |
| 玩家死亡 | 在 `lastAnchor` 处复生 | 无次数限制、无资源掉落（掉落项存疑，见下节） |
| 使用「回锚点」道具 | 玩家位移至 `lastAnchor` | 无（此路线不绑定刷新） |
| 使用「地图直传」道具 | 等价于在庙内选择传送 | 同上，绑定刷新 |
| 进入新一轮轮回 | 全部庙退回锁定态 | 角色/资产状态保留 |

值得照搬的三个设计选择：

1. **激活必须是显式动作**。靠近不点亮，让玩家为每座庙付一次操作成本，「点亮地图」才有实感，也让「忘了上香 → 死亡白跑」成为一个真实的风险记忆点。
2. **恢复与刷新绑定，而不是恢复与次数绑定**。代价来自世界状态被重置（要多打一遍小怪），而不是「今天还能休息几次」这种人为额度 —— 玩家可以用操作技巧压低代价，也可以主动刷怪把它变成收益。
3. **传送自带恢复是保护而非漏洞**。不允许「无损传送」意味着玩家永远不可能在残血状态下被扔进敌群：既然移动必然回满，那么「传过去就打」始终是可控决策。

反面教训：**跨章节全量传送 + 全场景刷新**这两条叠起来，使「清完全图再传送」变成重复劳动，是社区对跑图体验最集中的抱怨点之一；而地图系统（行旅图）是上线四个多月后才补上的 —— 锚点系统本身够用，但**没有任何导航层**会放大它的摩擦。
