# 更新日志

版本号按语义化版本（semver）：破坏性改动升主版本，新功能升次版本，修复与重构升修订号。

## 0.5.0（未发布）

重构与可测试性建设，无玩法变化。

- 架构：modmain 拆出 `landshrine_strings`（文本）、`landshrine_util`（跨端查询）、
  `landshrine_debug`（调试入口）三个模块；新增纯逻辑模块 `landshrine_slots`
  （槽位白名单解析 + 占用槽字符串协议，编码/解码两端共用一份实现）
- 数值归一：上香距离、传送半径、落点搜索距离、小地图图标名、音效事件名、
  tag / 事件名全部集中到 `landshrine_config.lua`
- 降低耦合：网络组件不再向土地庙实体注入字段，拆庙注销统一走组件
  `OnRemoveEntity` 回调；原版内部字段 `icon._target` 的读取封装进 util
- 测试：新增离线单元测试（`tools/test/`，本机 Lua 5.1 运行，14 项）与
  游戏内场景测试（控制台 `LandShrineTest.RunAll()`，覆盖建造/激活/传送/拆庙释放槽位）
- 存档：`landshrine` 组件存档增加 `version` 字段与迁移脚手架（当前版本 1）
- 文案：modinfo 作者、简介更新（去掉硬编码的槽位上限数字）
